Grid-Layout Klassen (Spalten)


.grid-container
Wrapper für alle Spalten. Immer als äußerstes Element verwenden.

.grid-item
Jede Box im grid-container benötigt diese Klasse.
Setzt automatisch 8px Aussenabstand links/rechts und 16px unten.

.col-3      Breite 25%    (4 Spalten nebeneinander)
.col-4      Breite 33%    (3 Spalten nebeneinander)
.col-6      Breite 50%    (2 Spalten nebeneinander)
.col-8      Breite 66%    (breite Hauptspalte)
.col-12     Breite 100%   (volle Breite)


Responsive Klassen (Fenstergröße)


.responsive
Box passt sich der Fenstergröße an und bewegt sich mit.
Nutzen wenn ein Element flexibel mit skalieren soll.

.fill
Füllt den gesamten verfügbaren Platz aus (Breite und Höhe).

.center
Zentriert das Element im Elternelement.

.anchor-top-left
Element klebt oben links, auch beim Größen ändern.

.anchor-top-right
Element klebt oben rechts, auch beim Größen ändern.

.anchor-bottom-left
Element klebt unten links, auch beim Größen ändern.

.anchor-bottom-right
Element klebt unten rechts, auch beim Größen ändern.

.fullscreen
Element füllt den gesamten Bildschirm aus (z.B. für Hintergrund-Panels).

Regeln

1. Keine manuellen Pixelwerte in UXML - immer Grid-Klassen nutzen
2. Jede neue UXML-Datei muss die GridSystem.uss einbinden
3. grid-item immer zusammen mit einer col-Klasse verwenden
4. grid-container nie als grid-item verwenden
5. Mehrere Klassen können kombiniert werden
